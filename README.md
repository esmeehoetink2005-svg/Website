# Van weten naar doen

Portfoliowebsite bij de individuele strategische koersopdracht van Esmee Hoetink
(Commerciële Economie, Sales, HAN, 2026–2027): van productverkoop naar waardeverkoop.

Eén statische pagina (`index.html`) zonder build-stap of externe scripts. Lettertypes komen van
Google Fonts, foto's van Unsplash.

## Bekijken

Open `index.html` in een browser, of zet GitHub Pages aan voor deze repository
(Settings → Pages → Deploy from a branch → kies de branch en `/ (root)`).

## Foto's vervangen

Zoek in `index.html` naar `images.unsplash.com` en vervang de `src` door een eigen foto.
Kan een foto niet laden, dan toont de pagina een donkere kleurverloop als achtergrond.
